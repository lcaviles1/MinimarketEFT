# Security Policy

## Reporting a vulnerability

Please report security issues privately to Lucas Avilés Arias (https://github.com/lcaviles1).

Do not open public GitHub issues for suspected vulnerabilities.

For non-security bugs, use the issue tracker: https://github.com/lcaviles1/MinimarketEFT/issues

## Scope

This policy applies to the generated Lucas Avilés Arias SDK packages published from this
repository (npm, PyPI, Packagist, RubyGems, LuaRocks, and the Go module).

This is an unofficial SDK for the MiniMarket Products public API, generated by
Lucas Avilés Arias. It is not affiliated with, endorsed by, or sponsored by the upstream
API provider.
